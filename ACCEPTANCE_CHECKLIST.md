# Visual Acceptance Checklist

## Material DNA
- [ ] Deep dark canvas uses restrained ambient lighting.
- [ ] Glass panels preserve translucency and depth.
- [ ] Borders remain subtle and low-contrast.
- [ ] Highlights do not become bright plastic outlines.
- [ ] Shadows remain soft and diffused.

## Palette Engine
- [ ] Palette switch recolors canvas, ambient light, surface tint, accents, highlights and data visualization.
- [ ] No stale teal/green tint remains when another palette is selected unless intentionally part of that palette.
- [ ] Components consume semantic tokens rather than preset-specific Hex values.
- [ ] Preset UI uses five-color mini strips.
- [ ] Custom five-color palette can be applied if exposed.
- [ ] `US-11 blue-gold` keeps gold localized and blue dominant.
- [ ] Effect tokens can be disabled without breaking readability.

## Typography / Layout
- [ ] Typography hierarchy is clear.
- [ ] Chinese and Latin render with system-safe fonts.
- [ ] Layout matches the user's information architecture.
- [ ] The canonical three-region composition is used only when appropriate.
- [ ] No unintended horizontal overflow at 1536×864 or 1366×768.
- [ ] Narrow-screen adaptation preserves hierarchy.

## Validation
- [ ] Generated page is actually opened in a browser.
- [ ] Palette panel and at least three palette switches are tested.
- [ ] Console contains no UI-related errors.
- [ ] Screenshots are generated and visually inspected.
- [ ] Visual consistency is not claimed from source inspection alone.
